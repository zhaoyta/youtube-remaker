# 抖音钓鱼爆款标题 / 内容（2026-08）

给「鱼公移山」掉点片用。标题尽量 **20 字内**。开头 5 秒要有地图钉、区名大标题或一句狠的。

## 现在还在吃的套路

1. **掉点白给**：定位拿走、免费、别交坑费  
2. **反转**：听说能爆护 → 去了全是小非 / 保安赶人  
3. **对比抬杠**：海鸥岛 vs 十九涌、挂绿湖白天 vs 夜口  
4. **自嘲空军**：钓鱼佬从不空军（带回来的是鸡、螺、知了）  
5. **避坑**：水源地、禁钓牌、三月到六月禁网具  
6. **数字**：36 个点、7 个区、8 个增江点  
7. **求补全**：你还知道更好的吗 → 评论区要导航

热门话题（播放量大，可挂 1–2 个）：`#原来钓鱼才是抖音运动顶流` `#dou是钓鱼人` `#钓鱼的乐趣只有钓鱼人懂`

## 内容形态（比标题更决定完播）

掉点合集本身完播偏难（6 分钟长），爆款更常是：

- **30 秒一条一点**：一个区名大标题 + 一张地图 + 一句优缺点  
- **对比片**：海鸥岛 vs 十九涌，两个地图来回切  
- **劝退片**：水源地 / 禁钓牌 / 三月禁网具  
- **评论区征集**：下期补你丢的点  
- **空军自嘲**：探点当天没鱼，只讲路和停车  

标签每条 5–8 个，前 3 个固定 `#鱼公移山 #广州钓鱼 #免费钓点`，后面轮换地点词：`#增江 #南沙钓鱼 #海鸥岛 #挂绿湖 #万顷沙 #长洲岛`。
