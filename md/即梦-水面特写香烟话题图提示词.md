# 即梦提示词：水面 POV + 手拿香烟特写

## 用法

- **画面固定**：构图、机位、人物局部、鱼竿位置每次不变
- **唯一变量**：香烟牌子（上传该牌真烟/烟盒参考图作垫图）
- **文案**：配生活感悟口播/文案引起评论

---

## 主提示词（直接复制到即梦）

```
第一人称俯视特写，镜头朝下对着水面。画面下方可见双腿大腿部位（短裤、皮肤质感真实），一只手伸入画面中央特写，手指夹着一根点燃的香烟，香烟侧面 Logo 清晰可见、包装印刷质感真实。旁边斜放一根鱼竿，竿梢延伸向水面。前景是清澈或略带波纹的河面/湖面，可见水面反光、细微波纹。自然日光，真实摄影感，浅景深，手和香烟最清晰，水面和大腿略虚。竖构图 9:16，抖音封面风格，写实，不要卡通，不要夸张烟雾，只有一缕细烟。
```

## 垫图设置（关键：用真烟图）

| 槽位 | 上传什么 | 权重建议 |
|------|----------|----------|
| 参考图1 | **该牌子真烟特写**（烟支侧面 Logo 清晰） | 高（0.7–0.85） |
| 参考图2（可选） | 烟盒正面 Logo | 中（0.4–0.6） |
| 参考图3（可选） | 上一张「固定构图」成片 | 中低（锁构图） |

**操作建议：**

1. 先做出一张「满意构图」当母版（香烟可先用通用烟）
2. 之后每次只换参考图1的烟牌，主提示词几乎不动
3. 在提示词末尾加：`严格参考上传香烟的真实外观、颜色、Logo 字体与比例，不要改成其他牌子`

## 换牌子时只改这一句（追加到主提示词末尾）


## 构图锁定句（系列统一时追加）

```
保持与参考成片相同的机位、大腿位置、手势、鱼竿角度与水面占比，仅更换香烟外观与 Logo。
```

## 生活感悟配文（引起话题，可轮换）

任选一条，或同结构换词：

1. **选择**  
   人这一辈子，很多时候不是选对了，是选习惯了。烟是，路也是。

2. **沉默**  
   水面最安静的时候，脑子反而最吵。有些话，只能跟烟说。

3. **代价**  
   谁都知道不好，可成年人的快乐，本来就带点代价。

4. **陪伴**  
   竿在手里，烟在手里，人在岸上。说孤独也孤独，说自由也自由。

5. **借口**  
   别人问我为什么抽烟，我说想清楚一件事。其实只是想停一下。

6. **年龄**  
   年轻时抽的是帅，现在抽的是撑着。

7. **比较**  
   鱼不上钩没关系，人要是一直不上道，才真难受。

8. **真相**  
   很多道理都懂，但懂了也不改，这才是生活。

9. **节奏**  
   世界跑得太快，我就坐河边抽一根，把时间骗回来一点。

10. **话题钩子（更适合评论区）**  
    你觉得抽烟的人，是贪图刺激，还是缺个安静的借口？

## 发布时可叠的短标题（画面内/封面字，可选）

即梦若另开「文字」能力，建议短、少：

- `成年人的暂停键`
- `有些话只跟烟说`
- `岸边想通一件事`

画面内文字尽量少，主要靠文案区引发讨论。

---

## 平台注意（简短）

- 真烟 Logo 依赖**垫图**；纯靠文字写牌子，即梦常画不准或审核拦截。
- 抖音等平台对香烟展示可能限流，文案偏「生活感悟」比硬广更稳。
- 系列化：同一母版构图 + 不同烟牌垫图 = 观感统一、辨识度靠烟。
