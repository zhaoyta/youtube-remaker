# 口播/字幕规范

## 规则

1. **文案 = 语音**：硬字幕原文必须等于该段 TTS 的 `script`，禁止另写摘要字幕。
2. **不要一坨糊底部**：按标点拆成短句，按字数比例切换显示；同一时刻只出当前一句。
3. **写口播时要断句**：`script` 用逗号/句号自然断气，避免无标点长串。
4. 标题/简介另写，不进画面字幕。

## 落点

- 成片逻辑：`skills/youtube-fishing-remake/scripts/remake.py`（`split_script_cues` / `build_subtitle_filters`）
- Skill 规范：`skills/youtube-fishing-remake/SKILL.md`
- Gemini 提示：`prompts/analyze.txt`、`prompts/analyze_parody.txt`
- 核对文件：`output/<id>/subs/*.txt`
