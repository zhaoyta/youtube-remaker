# 钓鱼教学课写法

课题每次由用户给。这里只规定课怎么写、图怎么用。

## 3 分钟结构（6～10 页）

1. **冷开场** `title`：先丢钩子再进干货。点名听众多谁（小白/老手交过学费）、一句威胁或反常识（千万别被忽悠 / 别先掏钱），再亮本集结论。禁止第一句就进店里场景、禁止说明书开篇。
2. **你是不是一直这样做** `hero`：点出常见错法，让人停下来。
3. **原理就一句** `hero`：一个物理或鱼情原因，不要百科。
4. **对照** `compare`：对 vs 错，或 A vs B，两张真图并排。
5. **怎么选 / 怎么做** `hook` 或 `steps`：给型号、号数、步骤。
6. **翻车点**（可选）`hero`：这招什么时候失效。
7. **记住这一条** + **outro**：评论区提问；outro 必须配一张有趣相关图（喜获、翻车、对比图），不要黑屏空场。

每页只讲一个点。听完要能动手，不要「了解一下」。一集只做一个决定，别塞满百科。

## 口播

- 约 4 字/秒。全文 650～780 字 ≈ 3 分钟。每页 35～85 字。
- **开头 5 秒必须有钩子**：对象感（「路亚小白听好」）+ 避坑威胁（「别被忽悠」）+ 一句反常识结论。再写店里/品牌细节。
- 像跟钓友当面说，有脾气、有画面。禁止写成百度百科朗读。
- 叫真名：伊势尼、3 号袖、0.8 主线、调四钓二。禁止「那种圆钩」「普通鱼」。
- 给可执行结论：鲫鱼用 3～4 号袖，鲤鱼 5 号伊势尼起。
- 禁止：大家好、家人们、能派上大用场、结构独特、直接拉满、太绝了、干货满满、首先其次再次。
- 开场钩子示例（换课题时改内容，别照抄）：「路亚小白进店前先听一句，千万别被店员先带进品牌坑——」

标题 15～25 字，简介 40～80 字补一句看点。标签 5 个，必须含 `#鱼公移山`。

## 图必须对得上实物

| 东西 | 来源 | 禁止 |
|------|------|------|
| 鱼 | `catalog/fish.json` 学名 → Wikimedia 真图 | 金鱼当野鲫、锦鲤当野鲤、海鲈当加州鲈、AI 鱼 |
| 钩 | `catalog/hooks.json` 几何+号数比例 | 随便一张钩图标成伊势尼；3 号袖画得和 3 号伊势尼一样大；有倒刺画成新关东 |
| 线 | `catalog/lines.json` 尼龙/碳线/PE | PE 画成透明单丝；尼龙画成编织纹；把 PE 号当尼龙拉力；台钓子线用 PE |
| 活饵 | `catalog/baits.json` Wikimedia | 红虫当蚯蚓（红虫是摇蚊幼虫）；沙蚕当红虫；整穗玉米冒充挂钩玉米粒 |
| 商品饵状态 | 按状态画：拉饵有丝、搓饵实心球、散炮干散 | 拉饵画成光滑圆球；画老鬼/化氏品牌袋 |
| 漂/线组/坠 | `catalog/gear.json` | 台钓顺序画错；爆炸钩画成单钩；水滴坠画成铅皮 |

钩型辨认（画错直接重来）：

- **伊势尼**：钩底接近正圆，钩门宽，钩条粗，有倒刺。同号比袖大一圈
- **袖**：钩柄明显长，钩门窄，钩条细。鲫鱼常用 2～4 号
- **海夕**：介于袖和伊势尼
- **新关东**：无倒刺，钩尖明显内弯
- **千又**：钩门特别宽，钩尖内抠
- **伊豆**：钩弯不在同一平面，钩尖略歪
- **丸世**：钩柄很长，常见串钩

线（口播必须叫材质+号数，例如「0.8 号尼龙子线」）：

- **尼龙**：单丝、半透明。台钓主线、子线。子线必须比主线细
- **碳线**：单丝更透更硬。子线或路亚前导
- **PE**：多股编织，不透明。路亚主线。不用在台钓子线上

饵：

- **红虫** = 摇蚊幼虫 Chironomus，细小鲜红分节，不是蚯蚓
- **蚯蚓** = 红蚯蚓 Eisenia fetida，不是沙蚕
- **拉饵**有纤维丝，**搓饵**是实心圆/椭圆，**散炮**干散入水就散

鱼种/活饵目录没有时：查学名 → Wikimedia 搜到**该种**照片 → 写入对应 catalog → 再引用。搜不到就不要那一页，不要用近缘种顶替。
